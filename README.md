## ⚡ Highlights & Features

* **⚡ Two-Stage Preloader:** Counter loop loading telemetry from `00` to `100` followed by an illuminated **BAROT MEET** splash screen.
* **💻 Dynamic Matrix Background:** 180+ floating laptop & desktop vector particles running on the HTML5 Canvas API.
* **🃏 Glassmorphic 3D Tilt Cards:** Interactive cursor coordinates tracking with 3D perspective physics.
* **📱 Fullscreen Snap Scroll:** Page-by-page swipe navigation (`scroll-snap-type: y mandatory`).
